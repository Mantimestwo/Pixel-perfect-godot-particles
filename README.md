# Pixel-perfect-godot-particles
Simple Godot plugin for adding a single custom node, inherited from Godot's base GPUParticle2D and using a custom script on top, to control shoddily modified particle process shader code to have access to pixel-perfect 2D particles, available in both C# and GDScript.
